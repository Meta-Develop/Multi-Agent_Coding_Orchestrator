# Per-class Terminal-Bench 4.0 reference, 2026-11-04

The adjacent [version-1 operator snapshot](public-tb4-2026-11-04.json) is
repository-relative and parseable by `--prior-data`. It is not bundled. Both
`models` arrays are empty, so it adds no operator class-fit, no capability
eligibility, and no judgment authority. Passing selection preflight with this
file is not live qualification, not a class-fit sample, and not acceptance.

Public reference lanes are chosen per task class. Bounded localized code
changes are the simple class, so the reference is the cheapest requested
effort of the Codex model the operator already uses for that class:
`codex` / `gpt-6.1-sol` / `low`. Stronger Sol efforts stay off this mapping.
Harder work has no reviewed public mapping, so a public-only lane stays
refused there. The unchanged 8000-bp floor applies to the relative ratio
`min(10000, floor(10000 * lane_score / reference_score))`.

Production Worker assignments carry `localized_code_change` (terminal leaf,
bounded). Researcher assignments carry `review_gate`. The plan schema stores
a role, not a task class; the planner lowers a direct worker to one terminal
Worker, and the selection bridge assigns the class from that role. This
snapshot maps only `localized_code_change`. It does not map `review_gate`,
research, delegation, or any judgment role. Child orchestration uses the same
class string but delegating authority and a shape outside the bounded
terminal ceiling, so this evidence does not apply there either.

bound, not a date printed on the score table. It is the later of:

## What stays refused

row for any other task class, so it stays refused for research, review, and
every non-terminal authority role. Deleting a mapped row leaves that effort
unknown rather than a fabricated zero. The [2026-11-03 checkpoint](grok-public-2026-11-03.md)
still grants nothing by itself.
